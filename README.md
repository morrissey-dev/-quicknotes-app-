         #QUICKNOTES APP
# Description

QuickNotes is a simple browser-based notes application that allows users to create, search, and delete notes. Notes can be organized into different categories and are saved in the browser using localStorage, so they remain available after refreshing the page.

## Features

* Add notes with different categories
* Search notes by text
* Delete notes
* Validate notes from 1 to 200 characters
* Display the total number of notes
* Save notes using localStorage
* Load saved notes when the page opens
* Responsive design for smaller screens

## How to Run Locally

1. Download or clone the QuickNotes repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Start adding and managing your notes.
